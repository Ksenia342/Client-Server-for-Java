# 🖥 Клиент-серверное приложение на JavaFX

Десктопное приложение с графическим интерфейсом на **JavaFX**. Клиент общается с сервером по **TCP**, а доступные функции зависят от роли пользователя.

## ✨ Возможности

- 🔐 вход в систему и регистрация новых пользователей;
- 👥 три роли с отдельными меню: **администратор**, **пользователь**, **работник**;
- ⚙️ личный кабинет: просмотр и изменение логина и пароля;
- 🌐 обмен данными с сервером по TCP (запросы и ответы);
- 🔌 корректное отключение от сервера при закрытии приложения.

## 🛠 Технологии

- Java
- JavaFX (FXML-сцены)
- TCP-сокеты
- Сериализация данных между клиентом и сервером

## 🚀 Запуск

1. Запусти серверную часть приложения.
2. Запусти клиент (класс `main.Main`).
3. Войди в систему или зарегистрируйся.
